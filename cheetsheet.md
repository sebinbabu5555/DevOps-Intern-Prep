# Day 7 — Linux and Git Cheat Sheet

## Linux commands

1. `pwd` — Shows my current directory.
2. `ls -la` — Lists files, including hidden files, with details.
3. `cd foldername` — Changes my current directory.
4. `mkdir foldername` — Creates a directory.
5. `touch filename` — Creates an empty file if it does not exist.
6. `cat filename` — Displays file contents.
7. `ls -l` — Displays file permissions, ownership and other details.
8. `chmod` — Changes file permissions.
9. `grep "word" filename` — Searches for matching text in a file.
10. `echo "text" > file.txt` — Writes text to a file, replacing existing contents.
11. `echo "text" >> file.txt` — Appends text to a file.
12. `command --help` — Displays command help when supported.

## Git commands

13. `git status` — Shows the state of my working tree.
14. `git add filename` — Stages a file.
15. `git commit -m "message"` — Creates a commit from staged changes.
16. `git log --oneline -5` — Shows the five latest commits.
17. `git diff` — Shows unstaged changes to tracked files.
18. `git diff --staged` — Shows staged changes.
19. `git pull` — Fetches remote changes and integrates them into my current branch.
20. `git push` — Uploads local commits to a remote repository.
