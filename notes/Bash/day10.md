# Day 10 — Bash Loops and Command Substitution

## What I learned
- A `for` loop repeats commands for multiple items.
- `do` begins the loop body, and `done` ends it.
- `$(command)` runs a command and captures its output.
- `-f` checks for a regular file.
- `-d` checks for a directory.
- `if`, `elif`, and `else` allow a script to make decisions.

## What I built
A Bash script that checks multiple paths and reports whether each is a file, directory, or missing path.

## Command substitution examples
- `today=$(date +%F)`
- `current_dir=$(pwd)`
