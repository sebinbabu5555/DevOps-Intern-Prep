# Day 5 — Git Fundamentals

## Learning goals

- Understand the working tree, staging area, and repository.
- Use git status, git add, git commit, git log, and git diff.

## Commands learned

- `git status` — checks the state of files.
- `git add FILE` — stages changes to a file.
- `git commit -m "MESSAGE"` — records staged changes.
- `git log --oneline` — displays commit history.
- `git diff` — displays unstaged changes.
- `git diff --staged` — displays staged changes.
