# Linux Server Health and Log Monitor

## 1. Project Overview

The Linux Server Health and Log Monitor is a beginner-friendly Bash scripting project designed to collect basic system information and analyse application logs.

The project demonstrates Linux command-line skills, Bash automation, file checks, and basic troubleshooting.

## 2. Objectives

- Collect basic Linux system information.
- Display disk and memory usage.
- Count ERROR messages in an application log.
- Save health-check results to a report file.
- Practise automation concepts relevant to DevOps.

## 3. Technologies Used

- Linux / Ubuntu
- Bash scripting
- Git and GitHub
- Linux command-line utilities

## 5. Planned Features
